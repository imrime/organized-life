## 2. Service worker (`sw.js`)

### 2.1 Behaviour
| Aspect | Rule |
|--------|------|
| Registration | Only on `https:`. On `localhost`/`127.0.0.1` it is **not** registered; existing registrations are unregistered and all caches deleted so development never mixes versions. |
| Code cache | `CACHE = 'organized-life-<sha8>'` (CI replaces `'organized-life-dev'`). Holds `ASSETS` (shell + code). |
| Code strategy | **Network-first**: network response is returned and stored in `CACHE`; the cache is used **only when offline** (navigation falls back to cached `index.html`). |
| Immutable cache | `IMMUTABLE_CACHE = 'organized-life-immutable'` — name never changes. Holds content-hashed files (`assets/**/<name>.<hash8>.<ext>`) and versioned vendor files. |
| Immutable strategy | **Cache-first** (hash in the name guarantees freshness). On install only **missing** immutable files are downloaded. On activate, entries not in the current list are pruned. |
| Lifecycle | `install` → precache → `skipWaiting()`; `activate` → delete old `organized-life-*` code caches (except current and immutable) → `clients.claim()`. Phones pick up a new version on the next launch automatically. |
| Scope | Same-origin `GET` only; everything else passes through. |
| ASSETS list | Must be updated with **every new module/CSS file**; `tools/check_sw_assets.py` enforces it in CI. |

### 2.2 Skeleton

```js
// Service worker for Organized Life.
// CACHE is replaced in CI with the commit SHA so every deploy gets a fresh code cache.
const CACHE = 'organized-life-dev';
const IMMUTABLE_CACHE = 'organized-life-immutable';

// App shell and code: network-first, cached for offline use.
// Add every new module here (verified by tools/check_sw_assets.py).
const ASSETS = [
  './',
  './index.html',
  './manifest.webmanifest',
  './css/tokens.css',
  './css/base.css',
  // …
  './js/version.js',
  './js/main.js',
  // …
];

// Content-hashed files: cache-first. Generated by tools/hash_assets.py — do not edit by hand.
// <immutable-assets>
const IMMUTABLE_ASSETS = [
  './js/vendor/htm-preact-standalone-3.1.1.mjs',
];
// </immutable-assets>

const scoped = (path) => new URL(path, self.registration.scope).href;
const isImmutable = (url) => /\.[0-9a-f]{8}\.[a-z0-9]+$/.test(url.pathname) || url.pathname.includes('/js/vendor/');

self.addEventListener('install', (event) => {
  event.waitUntil((async () => {
    const code = await caches.open(CACHE);
    await code.addAll(ASSETS.map((path) => new Request(path, { cache: 'reload' })));
    const immutable = await caches.open(IMMUTABLE_CACHE);
    for (const path of IMMUTABLE_ASSETS) {
      if (!(await immutable.match(scoped(path)))) await immutable.add(path);
    }
    await self.skipWaiting();
  })());
});

self.addEventListener('activate', (event) => {
  event.waitUntil((async () => {
    for (const key of await caches.keys()) {
      if (key.startsWith('organized-life-') && key !== CACHE && key !== IMMUTABLE_CACHE) await caches.delete(key);
    }
    const immutable = await caches.open(IMMUTABLE_CACHE);
    const keep = new Set(IMMUTABLE_ASSETS.map(scoped));
    for (const request of await immutable.keys()) {
      if (!keep.has(request.url)) await immutable.delete(request);
    }
    await self.clients.claim();
  })());
});

self.addEventListener('fetch', (event) => {
  const { request } = event;
  if (request.method !== 'GET') return;
  const url = new URL(request.url);
  if (url.origin !== self.location.origin) return;
  event.respondWith(isImmutable(url) ? cacheFirst(request) : networkFirst(request));
});

async function networkFirst(request) {
  try {
    const response = await fetch(request);
    if (response.ok) (await caches.open(CACHE)).put(request, response.clone());
    return response;
  } catch {
    const cached = await caches.match(request, { ignoreSearch: true });
    if (cached) return cached;
    if (request.mode === 'navigate') return caches.match(scoped('./index.html'));
    throw new Error('Offline and not cached: ' + request.url);
  }
}

async function cacheFirst(request) {
  const cache = await caches.open(IMMUTABLE_CACHE);
  const cached = await cache.match(request);
  if (cached) return cached;
  const response = await fetch(request);
  if (response.ok) cache.put(request, response.clone());
  return response;
}
```

### 2.3 Registration (`js/core/sw-register.js`)

```js
// Registers the service worker on https only; on localhost removes any worker and caches.
export async function registerServiceWorker() {
  if (!('serviceWorker' in navigator)) return;
  const isLocal = ['localhost', '127.0.0.1', '[::1]'].includes(location.hostname);
  if (location.protocol === 'https:' && !isLocal) {
    await navigator.serviceWorker.register('./sw.js', { scope: './' });
    return;
  }
  for (const registration of await navigator.serviceWorker.getRegistrations()) await registration.unregister();
  if ('caches' in window) for (const key of await caches.keys()) await caches.delete(key);
}
```

### 2.4 Tooling for the asset lists
- `tools/hash_assets.py` (Python 3.9+, stdlib only): for each file in `assets-src/` (images, sounds, fonts) compute SHA-256, take 8 hex chars, write `assets/<relative-dir>/<name>.<hash8>.<ext>` (skip if exists), delete stale hashed files, regenerate `js/asset-manifest.js` (`export const assets = { 'rooms/bedroom/bg.webp': './assets/rooms/bedroom/bg.3f9a1c2e.webp', … }`) and the block between `// <immutable-assets>` and `// </immutable-assets>` in `sw.js`. Run it after changing anything in `assets-src/`; commit the outputs.
- `tools/prepare_art.py <location>` (dev-only dependency: Pillow, `pip3 install --user pillow`): validates an owner-delivered art folder, converts PNG → WebP and prints measured hit areas ([08 §7](08-art-delivery.md#7-hand-off-and-integration-per-location)). Run before `hash_assets.py`.
- `tools/check_sw_assets.py`: lists every file under `js/` (except `js/vendor/`) and `css/` plus `index.html` and `manifest.webmanifest`; fails (exit 1) if any is missing from `ASSETS`, or if `ASSETS` references a file that doesn't exist. Also verifies each immutable entry exists.

## 3. GitHub Pages deployment

### 3.1 `.github/workflows/pages.yml`

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v7

      # Addition to the base template: fail fast before publishing.
      - name: Verify
        run: |
          python3 tools/check_sw_assets.py
          node tests/run-node.mjs

      - name: Build _site
        run: |
          set -euo pipefail
          SHA8="${GITHUB_SHA::8}"
          rm -rf _site && mkdir _site
          cp -R index.html manifest.webmanifest sw.js css js icons assets _site/

          sed -i "s/const CACHE = 'organized-life-dev';/const CACHE = 'organized-life-${SHA8}';/" _site/sw.js
          grep -q "const CACHE = 'organized-life-${SHA8}';" _site/sw.js || { echo "::error::CACHE substitution failed"; exit 1; }

          sed -i "s/export const BUILD = 'dev';/export const BUILD = '${SHA8}';/" _site/js/version.js
          grep -q "export const BUILD = '${SHA8}';" _site/js/version.js || { echo "::error::BUILD substitution failed"; exit 1; }

      - uses: actions/configure-pages@v6

      - uses: actions/upload-pages-artifact@v5
        with:
          path: _site

      - id: deployment
        uses: actions/deploy-pages@v5
```

Notes:
- Only app files are copied: `index.html`, `manifest.webmanifest`, `sw.js`, `css/`, `js/`, `icons/`, `assets/`. Docs, tools, tests, PDF and sources are never deployed. `assets/` and `icons/` must exist from Phase 0 (`.gitkeep` until real files arrive).
- The two `sed` patterns must match the source files **exactly** (including the trailing `;`) — the `grep -q` guards make the build fail otherwise.
- The *Verify* step is an addition to the base template; remove it only if tests become flaky (preferred: fix the tests).

## 4. Versioning

### 4.1 Single source: `js/version.js`

```js
// Single source of truth for the app version. BUILD is replaced in CI with the commit SHA (8 chars).
export const VERSION = '0.1.0';
export const BUILD = 'dev';
```

- Shown at the bottom of Settings: **`v0.1.0 · build 1a2b3c4d`** (locally `v0.1.0 · build dev`).
- Semver `MAJOR.MINOR.PATCH`:
  - `0.MINOR.0` per roadmap phase while < 1.0; `PATCH` for fixes;
  - `1.0.0` when all rooms and global acceptance criteria are met ([07](07-roadmap.md));
  - after 1.0: MAJOR = backup format/data incompatibility or removal of a feature, MINOR = new features, PATCH = fixes.
- `SCHEMA_VERSION` (data) is independent of the app version; a data migration requires at least a MINOR bump and a CHANGELOG note.

## 5. Release procedure

1. Bump `VERSION` in `js/version.js`.
2. Move `[Unreleased]` entries into `## [X.Y.Z] - YYYY-MM-DD` in `CHANGELOG.md`; update the links at the bottom.
3. Commit: `git commit -am "Release X.Y.Z"`.
4. Tag: `git tag -a vX.Y.Z -m "Organized Life X.Y.Z"`.
5. Push: `git push --follow-tags` — **done by the owner only**.

Before step 3: run tests (browser runner), `python3 tools/check_sw_assets.py`, and the manual QA checklist for MINOR releases ([07 §5](07-roadmap.md#5-manual-qa-checklist-per-release)).

## 6. Development workflow rules

| Rule | Detail |
|------|--------|
| Commits and tags | Created **locally**. Claude never runs `git push`. |
| Identity | Repository-local noreply identity, never the work e-mail: `git config --local user.name "imrime"` and `git config --local user.email "imrime@users.noreply.github.com"` (or the `<id>+imrime@users.noreply.github.com` address shown in GitHub → Settings → Emails). The current global e-mail must not be used for this repo. |
| Language | Code comments, commit messages and developer docs in **English**. UI strings via i18n (EN + RU). |
| Commit style | Imperative subject ≤ 72 chars ("Add alarm clock window"), optional body explaining why. |
| Branching | `main` deploys. Work on short-lived branches when convenient; merge/fast-forward locally. |
| Local run | `python3 -m http.server 8000` from the repo root → http://localhost:8000/ (service worker disabled). Tests: http://localhost:8000/tests/ |

### 8.2 Policy
- v1 needs **no secrets** (no APIs). Any future key (e.g. Web Push VAPID private key) lives only in `.env.local` (git-ignored) or GitHub Actions secrets — never in client code (a static site exposes everything it ships).

### 8.3 Secrets scan
Run before the first publication and before making the repository public:
```bash
git ls-files | grep -iE '(^|/)\.env' && echo "!! env file tracked"
git log --all -p | grep -inE '(api[_-]?key|secret|token|passw(or)?d|bearer |BEGIN (RSA|EC|OPENSSH) PRIVATE KEY)' | head
# Optional, more thorough:
gitleaks detect --source . --log-opts="--all"
```
Also check that no work e-mail appears in history: `git log --all --format='%ae %ce' | sort -u`.
