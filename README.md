# Organized Life

A mobile life-organisation app where everyday tools are objects in a hand-drawn 2D home: tap the alarm clock to set an alarm, the fridge to manage food, the ATM to see your budget. Portrait-only, installable PWA, all data stays on your device.

**Live:** https://imrime.github.io/organized-life/

- Specification: [docs/spec/README.md](docs/spec/README.md)
- Development, publishing and releases: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)
- Changes: [CHANGELOG.md](CHANGELOG.md)

Quick start:

```bash
python3 -m http.server 8000
# app:   http://localhost:8000/
# tests: http://localhost:8000/tests/
```
